## 2. 运镜与控制技术前沿突破（关键经验）

1. **直接调用 Five SDK 驱动，彻底淘汰普通鼠标盲点与卡死**：
   - 网页运行的是如视 Five SDK (v6.6.20)；
   - 最佳运镜指令：`five.moveToPano(panoIndex, { effect: 'fly', duration: 1500~2000, longitude: rad, latitude: 0, fov: 95 })`；
   - **平移与转向同步（Simultaneous Movement）**：必须位置和视角共用 duration。严禁“先冲向一面白墙停下，再机械转头”。

2. **高帧率纯净录制方案（已被 T03 验证为业界最佳实践）**：
   - 不使用系统外部录屏（容易掉帧到 10fps）；
   - 直接从页面渲染 Canvas 提取流：`canvas.captureStream(30)`，配合 `MediaRecorder` 录制 720×1280 竖屏 WebM/VP9；
   - 实测可稳定达到 **29.95 fps** 纯净高帧率，相邻帧时间戳严格递增无掉帧！
   - 开录前通过 DOM 操作注入 CSS，隐藏顶底导航条、经纪人名片、小地图和工具箱，保留原汁原味的三维实景。

3. **视觉叠影与形变的客观规律（必须尊重的物理边界）**：
   - 如视全景切片在跨门框、穿墙角平移时，由于全景球融合算法，**中间帧会有短暂的半透明叠影与门框拉伸**；
   - 这是三维全景重建的底层物理机制，并非代码 Bug，不能通过加速或跳剪伪装；
   - **合规与宣传准则**：在画面底部保留小字注明：“*如视VR点位漫游 · 空间现状以现场为准*”，不宣称“真人手持真实摄影”。

4. **文案与事实红线（前序工程严格核定）**：
   - **不可宣称**：禁止使用“一线江景”、“无遮挡湖景”、“全赠送花园”（实勘窗外为邻近楼栋与建筑景观）；
   - **真实事实依据**：
     - 4间卧室、2个卫生间、2个阳台、1个衣帽间；
     - 客厅标称 30.9㎡，阳台A标称 9.1㎡，阳台B标称 7.8㎡，卧室B套房标称超 24㎡；
     - 突出“南北双阳台对流”、“四开间朝南超大面宽”、“动静分区明确”、“主卧豪华套房”。
   - **配音规范**：采用 MMX 温暖女声（`speech-2.8-hd` / `Warm_Bestie`，语速 0.96，不加突兀 BGM，留足呼吸感与空间留白）。
