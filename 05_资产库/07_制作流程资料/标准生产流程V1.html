房产介绍视频制作流程 V1：真实性门禁优先

资料可自动整理，真实房屋不能自由生成。总览先定内容骨架；具体脚本、动作与素材每次只落地当前一镜。

① 输入与分析

房源资料／用户要求
保留原件、房源ID、时间与SHA
→
清洗／结构化事实
标称、产权、视觉、未知分开
→
卖点／缺点／受众
区分事实与买家假设
→
视频定位／内容骨架
主张排序、时长预算、素材可得性
人工门禁：房源与资料匹配；无证据数字/结构/价格不得进入脚本；定位与发布范围先确认。

② 当前镜头闭环（不是批量写完再测）

当前镜口播／分镜
一句主张对应一处视觉证据
→
真实素材／点位探测
VR、实拍或图片；能力不足降级
→
试录／配音预算
可达、贴图、语音实长、舒适度
→
技术＋事实＋人审
绑定take与SHA，批准具体范围
未通过 → 只整改当前镜　｜　通过 → 下一镜　｜　全部镜头通过 → 才进入整片合成

③ 输出与发布门禁

实际时间轴／素材编排
不沿用旧音轨；输出拒绝覆盖
→
剪辑／字幕／音乐包装
事实一致、图声授权、安全区
→
完整看片／听音／QA
技术、视觉、事实、权利分判
→
人工签认／成片归档
具体版本、变更记录、失败样本
禁止：AI改户型、门窗、房间数、阳台、朝向、面积、装修或空间关系；未知价格/周边不得杜撰；不把全景缩放当位移，不用生成式画面掩盖缺点。

方言分支（后续验证）：标准事实 → 标准脚本 → 当地口语 → 本地用词/身份审核 → 配音 → 实测语速与镜长 → 标准字幕 → 事实一致性。两案例真实验证之后才固化生产Skills。
