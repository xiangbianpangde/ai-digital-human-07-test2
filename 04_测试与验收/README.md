## 3. 验收门禁要求
1. **画质纯净**：必须通过 WebGL Canvas 原生流捕获，无任何页面文字、名片、弹窗与小地图污损；
2. **净空与穿模边界**：离墙/门框≥0.5m是目标要求；当前未做米级距离量测，metric_clearance保持unverified。点位可达、接触表视觉接受不能认证0.5m净空；
3. **连贯无停滞**：位移转换与视角旋转必须深度耦合，严禁直面墙壁停滞。
