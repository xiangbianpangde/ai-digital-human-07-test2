# 实现工具导航

> 本目录已包含单项方法执行、配音与终片合成实现，不再是Stage2/3空预留目录。实时范围看[当前入口](../00_入口/00_当前.md)。

| 实现 | 用途 | 运行边界 |
|---|---|---|
| [方法库/](方法库/README.md) | 索引选择门禁、原生浏览器/SDK单动作接收、后期/静默示范、安全变体、review与只读复验 | 读取[AI执行说明](../05_资产库/06_房产摄影运镜模式库/AI执行/README.md)；一次一项、新take、授权后执行 |
| [generate_audio.py](generate_audio.py) | 调用mmx生成既有六段配音 | 固定台词/房源/路径，会写文件及调用服务；不可直接重跑 |
| [audio/cues_manifest.json](audio/cues_manifest.json) | 六段文本、目标起点、预算与实际语音时长 | 是历史产物清单，不是全片同步认证；存在超预算片段 |
| [render_final_video.py](render_final_video.py) | 拼接S1–S5、混合音频、开场闪卡与单行双色字幕、生成终片接触表 | 固定路径、字体、时轴，`ffmpeg -y`可覆盖；未经新任务不运行 |
| `overlays_v2/`、音轨/母带等 | 第一套既有制作衍生物 | 保留原位；修改用新版本，不能覆盖原片或假称新take |
| [第二套首镜专用试验](02-武汉104119325592/首镜原生定点试验/README.md) | 已获准pano1/front、6秒静默定点转向；真实面透视重投影与无音轨编码 | 固定本次合同/SHA与take01，14项预检、防重跑；不进入下一镜，不是通用Skill或网页SDK/真人走动 |

现成单项方法库是较安全的复用入口；生产脚本尚不具备跨房源参数化和防覆盖输出能力。后续改造先明确输入/输出、依赖、授权及停止条件，不把当前脚本包装成未验证的一键skills。

前轮资料整理仅运行[方法库复验](../04_测试与验收/资料整理核验/方法库复验-20261005.json)、ffprobe及只读解码/哈希。后续获准第一片最小修订和第二套首镜静默试验，分别另存；第二套只有一个take01，来源面不改、无新TTS/付费，待用户审看。最新权限/阶段只看00_当前。
