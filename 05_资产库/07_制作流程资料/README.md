## 3. 本案例的可核验成果

- 标的：武汉·沙湖九号。约163㎡、4室2厅2卫2阳台1衣帽间；123.7㎡是12个空间的标称面积求和，口播口径为“套内约124平米”，不是产权测绘或公摊认证。
- [参考片](../04_参考视频/reference_video.mp4)：34.166667秒，720×1280；与用户指定的原MP4字节一致。
- 用户提供的户型图、三维模型截图均已永久归档，[原户型图](../01_户型图/floorplan_source.png)、[原模型截图](../02_三维建模/3d_model_source.png)与临时源文件SHA-256一致；不需要重复复制临时文件。**裁切图AST-002/004实际哈希与旧台账不一致，整理前已如此，复用前needs_reconcile；保留文件与旧哈希，不把原图匹配扩大为裁切图也通过。**
- [终片](../../04_测试与验收/S6_全片终成片交付/沙湖九号-核心卖点宣传短片-终版成片.mp4)：25.30秒，720×1280，H.264/AAC；视频759帧，时间戳核对为30fps。
- 终片视频流约1.124Mbps；音频流32kHz、单声道、约92.9kbps，时长24.493秒；不能照抄旧报告中的“192kbps”作为测量结果。
- 结构：客厅到阳台 → 阳台反打 → 北向房间 → 主卧/主卫 → 窗边CTA；呈现VR画面、配音和双色字幕。未据此认证数字人出镜能力或营销转化率。

## 4. 资料库的三层关系

| 层 | 内容 | 应怎样使用 |
|---|---|---|
| 来源与教学层 | 原图、参考视频、08教学库、07的四个旧模式目录 | 看原理、反例与使用记录；名称不等于能力已通过 |
| 本房源执行层 | `AI执行/方法库.json`、`点位.json`、单项执行器 | 先校验选择门禁，只复用精确配方；不能批量自动拍全片 |
| 不可覆盖的证据层 | `04_测试与验收/S1_*`至`S6_*`、`方法库实测/` | 查原片、遥测、技术检查、视觉review与授权时间；修改方案必须新take |

统一索引有**25个原方法**（10采集、10后期、5叙事）和**6个独立安全变体**。18个原配方及6个变体具备本房源复用条件；3个原后期视觉拒绝，4个原方法blocked。N01–N05只是静默图文示范，不能计作新全片/口播/数字人完成。

27个SDK点位均有房间元数据；统一方法库本轮视觉凭据涉及P1/P2/P5/P9/P10/P25，不是27点全部试拍。S1–S5是另一组生产证据，不与方法库点位覆盖混算。
