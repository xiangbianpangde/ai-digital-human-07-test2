## 目录标准化结构模板

```text
[模式目录]/
├── 演示视频_*.mp4         # 该手法的独立 MP4 演示片段
├── *.png                 # 关键帧拆解与正负面避坑截图
├── README.md             # 该手法的原理、参数约束与使用场景
└── 使用记录/              # 本项目各 Shot 实战应用与复盘记录
    └── REC-*.md          # 详细执行参数、缺陷诊断与整改要求
```
