## 执行原则与旧成果

内容骨架先定，具体当前镜台词/动作→立即探索/试录→技术/视觉/事实/相应人审→下一镜；全部准入后才整片合成。禁止先批量写全套具体脚本/路径再测试，失败只改当前镜，不用AI修改户型/房间/门窗/阳台/朝向/面积/装修/空间或虚构价格周边。

第一套[25.30秒终片（目录重排后的同SHA文件）](04_测试与验收/01-沙湖九号/S6_全片终成片交付/沙湖九号-核心卖点宣传短片-终版成片.mp4)已有五镜、普通话TTS和脚本剪辑；**业务收尾与当前暂停线以状态页为准**。第二套虽然同属沙湖九号，168.39㎡/36点/3阳台不同于上一套，不继承旧画面、参数或批准。

第一房源事实唯一来自[冻结核心档案](02_架构与合同/01_房产核心档案.md)；第二套09初始化仍是独立候选快照；获准首镜的事实仅取自[第二套最小档案](02_架构与合同/第二房源_104119325592/01_房产核心档案.md)及其来源绑定，不冻结全屋广告事实或修改第一套合同。方法复用仍读[AI执行说明](05_资产库/06_房产摄影运镜模式库/AI执行/README.md)并`catalog.py select ID`；选择通过只认证旧房源精确配方，不产生新许可。
